# Independent local sandbox CRM

This is a synthetic loopback-only HTTP process with a separate SQLite database. It requires Node.js 22.13 or newer (`node:sqlite` remains experimental on Node 22). It requires a random server-only token of at least 32 characters in `SANDBOX_CRM_TOKEN`; set `SANDBOX_CRM_DB` to an appropriate private local file and run `npm run sandbox`. Do not expose its port to a network or use customer data. `POST /tickets` initializes synthetic tickets; `POST /actions` performs a compare-and-set status update and stores an action receipt in the same transaction. `GET /receipts/:id?orgId=...` reads a receipt. The API authenticates a trusted Relay backend via its bearer token; it does not independently authenticate an end user.

The HTTP adapter only accepts an explicit `http://127.0.0.1:PORT/` URL, rejects redirects and rechecks the stored action payload hash. A disabled worker path now uses the database-backed dispatch store and reconciliation state machine. A local integration test covers a lost response after an approved action. Hosted credentials, network authorization and end-to-end worker behavior are not verified; do not enable it yet. Never expose the shared token to browsers or models. A production or hosted CRM deployment needs separate network, authentication, persistence, and isolation review.
